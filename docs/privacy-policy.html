This policy describes the Manifest V3 Nickspeare browser extension for Chromium and Microsoft Edge.

Effective date: 8 November 2026

What the extension does

Nickspeare generates invented Shakespearean-style usernames from a bundled evidence atlas. Generation runs locally inside the extension. The extension can also classify username-like fields on the active page after the user explicitly opens the popup and chooses Use on page, and can place a selected generated username into a field the user explicitly chooses.

Information handled locally

  • Preferences: generation rule, letter case, suffix, candidate count, length limits, reserved words, forbidden prefixes or suffixes, and seed are stored in chrome.storage.local under the versioned key nickspeare.preferences.v1.
  • Field descriptors: when the user requests page-field detection, the extension temporarily reads limited editable-field metadata such as element type, labels, accessible names, autocomplete hints, visibility, form context and whether the field is empty. These descriptors are used to present a field chooser and are kept in memory. Their values are not used to create a profile.
  • Generated names: candidates remain in the popup until replaced or closed. The extension does not maintain a remote or cloud history.

Information not collected

The extension does not collect, store or transmit passwords, one-time codes, payment-card data, cookies, authentication tokens, browsing history, account credentials, personal contact details or the contents of registration forms. Fields identified as email, password, one-time-code, payment-like, hidden or otherwise sensitive are excluded from insertion.

Network activity and remote code

The production extension does not contact a Nickspeare server or any third-party generation service. It does not load remotely hosted JavaScript, WebAssembly, stylesheets or executable code. The evidence atlas, engine, interface and image assets are bundled in the extension package. The extension works offline after installation.

Permissions

  • activeTab: grants temporary access to the active page only after the user invokes the extension.
  • scripting: injects the on-demand field bridge into that active page when the user chooses page insertion.
  • storage: saves the local versioned preferences described above.

The production extension requests no permanent or optional host permissions and does not run an always-on content script.

Retention and deletion

Preferences remain in the browser profile until the extension is removed or the browser profile is deleted. To clear them, open edge://extensions or chrome://extensions, remove Nickspeare, and reinstall it if desired. Removing the extension deletes its local extension storage. Generated names and temporary field descriptors are not retained after the popup closes.

Data sharing and sale

Nickspeare does not sell, rent, share or transmit personal data. There is no analytics, telemetry, advertising, account system, cloud sync or developer-operated backend.

Children

The extension is a general-purpose writing aid and is not directed at children. It does not knowingly collect personal information from anyone.
