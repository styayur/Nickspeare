# Nickspeare — 莎士比亚风格用户名生成器

**一座本地运行的命名工坊：一点市井的狡黠，一点王冠的庄严。**

Nickspeare 是一款离线优先的浏览器扩展，使用基于《亨利四世》第一部、《亨利四世》第二部与《亨利五世》构建的小型证据图谱，生成具有莎士比亚风格的用户名。它适合希望获得独特用户名、角色名、社交账号名称或写作灵感的人，不依赖远端生成服务。

扩展以紧凑的“命名工坊”弹窗呈现。你可以选择种子、一次生成四到六个候选名、查看每个名字的形成理由、复制候选名，或在当前页面上明确选择一个用户名字段后填入。所有生成均在本地完成，正式版本只申请 `activeTab`、`scripting` 与 `storage`。

## 功能

- 一次生成四到六个候选名；保持种子和控制项不变即可复现结果。
- 支持长度、大小写、数字、下划线、保留词、禁止前缀和禁止后缀等约束。
- 查看每个候选名的形成理由与来源关联的词语证据。
- 将候选名复制到剪贴板。
- 由用户主动选择当前页面上的用户名字段，并在确认字段说明后填入候选名。
- 在本地保存控制项偏好，重新打开弹窗仍可继续使用。

## 生成方式

内置证据图谱记录对白中的词语、来源位置、说话者分组和文本证据。Nickspeare 使用多种组合策略生成名字，包括“市井到王冠”的混合、字符级 Markov 造词、引文拼接与古语造词。本地评分器负责排序，界面会展示被选中名字的形成过程，并把历史年份解释为文学语境，而不是对现实账号可用性的声明。

扩展不会声称生成名是历史上真实存在的人名，也不会访问网站、注册机构、社交平台或账号系统来检查用户名是否可用。它不会自动注册账号。

## 安全的页面填入

页面填入完全由用户发起。打开弹窗、生成或选择候选名，点击 **Use on page**，再从可见的字段列表中选择目标字段。空字段默认填入；非空字段必须经过明确的替换操作。电子邮件、密码、一次性验证码、支付类、隐藏字段及其他敏感字段会被排除。扩展会触发正常的 input 与 change 事件以兼容受控组件，但绝不会自动提交表单。

正式版本不申请常驻站点权限，不运行常驻内容脚本，不收集浏览历史，也不读取 Cookie 或账号凭据。

## 隐私

所有生成资源均随扩展打包。正式版本不连接远端 API，不包含分析、遥测、广告、账号系统或云同步。偏好仅保存在 `chrome.storage.local`；移除扩展即可清除本地存储。完整的数据流说明请参阅公开隐私政策。

## 兼容性与限制

Nickspeare 是面向 Chromium 内核浏览器与 Microsoft Edge 的 Manifest V3 扩展，发布前会在 Chromium 与 Microsoft Edge 中验证。Firefox、页内自动建议徽标、iframe 扫描、closed shadow root 扫描、远端用户名可用性检测和自动提交表单不属于 v0.1.0-alpha 系列的范围。

本项目仍处于实验阶段。生成名是创意结果，不构成法律、商标或商业可用性意见；用于商业产品或公开身份前请自行判断并做必要检索。
